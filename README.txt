2.7 Studios Website
===================
Kholne ke liye: index.html ko browser mein double-click karein.

Folder structure:
  index.html        - main page
  css/style.css     - saari styling (colors top par :root mein hain)
  js/script.js      - menu, animations, contact form
  images/
    logo.png        - original logo (full quality)
    logo-web.jpg    - website par use hone wali halki logo image
    favicon.png     - browser tab icon
    project-1/2/3.png - Our Work section ki concept images

Apni pics lagane ke liye images/ folder mein file replace karein
(wahi naam rakhein) ya index.html mein img src badal dein.
Note: Google Fonts ke liye internet chahiye.
